## 👋 Welcome to the Pixel Journey

**`pixel-journey.github.io`** is the official flagship web portal repository powering [**pixeljourney.xyz**](https://pixeljourney.xyz) — the front door to an interactive, long-term, community-powered Web3 adventure where **crypto education, meaningful exploration, and pixel-perfect creation** sit at the very center.

While collecting and bonding over unique pixel art and NFTs is a joyful part of the experience 🖼️🎨, our core mission is to guide explorers and builders through the evolving Web3 multiverse — **one blockchain, one tool, and one milestone at a time.**

> 💡 **Our Philosophy:** *Build together, learn together, explore together.* We believe the best way to learn Web3 is by doing it hands-on. From your first self-custodial wallet quest to NFT crafting, DeFi liquidity, governance, and production code — you aren't just reading about Web3; you are living the journey.

## 🗺️ The Story So Far: Our Full Development Journey

Rather than rushing rigid hype cycles, Pixel Journey operates on **flexible, milestone-driven Seasons** backed by sustainable tokenomics and battle-tested engineering.

### 🌱 Phase 1: WAX Genesis & Foundational Mastery (2023 – Spring 2024)
* **Why WAX First:** We launched on the **WAX Blockchain** in 2023 for its carbon-neutral ethos, near-zero gas fees, rapid TPS, battle-tested **AtomicAssets** NFT standard, and seamless cross-chain bridges. It gave our community a friction-free sandbox to learn Web3 safely.
* **The Pixal PFPs (Spring 2024):** We minted our genesis 10,000 **Pixal PFP** collection, establishing digital identity, fractionalized liquidity via **$WPIXAL** (R-WAX), and the foundation of our collector economy.
* **The Sustainable $PXJ Economy:** Engineered for multi-year longevity with a predictable New Year's Eve minting model (~10% of remaining unminted supply allocated across `dao.pxj`, `team.pxj`, `dev.pxj`, `defi.pxj`, and `craft.pxj` pools).

### ⚙️ Phase 2: Ecosystem Mechanics & Community Governance (2024 – 2025)
* **Recycling, Blending & Crafting:** Launched **Pixel Ingredient Packs** (`pixelpack.pixeljourney.xyz`) and deep crafting loops that teach on-chain asset management while rewarding active participation.
* **The Rock Council & Leaderboards:** Established community-driven governance via the **WaxRocks / Rock Council**, the **$KING of Pixals** mechanics, and live progression tracking at [**lb.pixeljourney.xyz**](https://lb.pixeljourney.xyz).
* **Cross-Chain Horizons:** Expanded our educational footprint and bridging guides across **Ethereum, Polygon, Base, and Solana**, turning single-chain collectors into confident multi-chain navigators.

### 🧪 Phase 3: PxLabs, MiniDApps Alpha & The `PxPackages` Rebuild (Late 2025 – 2026+)
* **From Alpha MiniDApps to Modular Architecture:** Following intensive late-2025 Alpha experimentation across standalone miniDApps (`PxWallet`, `PxMarket`, `PxStaking`, `PxHot`), we executed a comprehensive architectural rebuild in 2026.
* **`PxPackages` & `PxPortals`:** Unified our frontend, state management, offline resilience, achievement badges, and verifiable on-chain mechanics into shared modular packages (**`PxUI`**, **`PxVault`**, **`PxPackages`**).
* **The Road to `PxLearn`:** Everything built across our GitBook and `PxPackages` converges toward the standalone **PxLearn Portal** — the most welcoming, interactive Web3 educational platform in the space.

## 💻 Repository Overview & Local Development

This repository contains the source code and static assets deployed via GitHub Pages to [**pixeljourney.xyz**](https://pixeljourney.xyz).

It is a pure static site (HTML + CSS + JavaScript). There is no build step or `package.json`.

### Quick Start
```bash
# 1. Clone the repository
git clone https://github.com/pixel-journey/pixel-journey.github.io.git
cd pixel-journey.github.io

# 2. Open locally (any of these work)
#    - Simply open index.html in a browser
#    - Or serve with any static server, e.g.:
npx serve .
#    - Or Python:
python3 -m http.server 8080
```

Then visit `http://localhost:8080` (or the port your server reports).

### Quality & Contribution Standards
* **Self-Custody & Security First:** Never commit private keys, API secrets, or unverified third-party scripts. Review our security practices and report vulnerabilities privately.
* **PX Perfection Standard:** All UI updates, copy changes, and documentation tweaks must align with [`pixel-journey-standards`](https://github.com/pixel-journey/pixel-journey-standards) for clarity, accessibility, and retro-pixel polish.
